# Skywood.club

Сайт-магазин подвесных палаток и гамаков-палаток Skywood. Продающий лендинг
с атмосферным видео и параллаксом, оплатой через **Т-Банк** и доставкой
**СДЭК** (включая оплату при получении — наложенный платёж).

Продавец: ИП Сурков К.А., ИНН 773135420168.

## Стек

Гибрид: статический фронтенд + бэкенд в двух реализациях.

- Фронтенд — статические HTML/CSS/JS (`public/`), без сборки.
- **PHP** (`public/api/`) — боевой бэкенд для обычного PHP-хостинга.
- **Node.js 18+ / Express** (`src/`) — тот же API для локальной разработки.
- Доступы — `public/.env`. Каталог — `public/data/products.json`.
  Заказы — `public/data/orders.json`.

## Развёртывание на хостинге (боевой режим)

Сайт работает на обычном PHP-хостинге — Node там не нужен.

1. Залейте папку `public/` в каталог сайта (или обновляйте её через
   `pull.php` — см. `spec/deploy.md`).
2. Откройте `install.php` в браузере — он проверит хостинг и подготовит
   папку `data/`.
3. Доступы Т-Банк и СДЭК — в файле `.env` рядом с `index.html`.

Обновление сайта из GitHub — открыть `pull.php` (тянет репозиторий и
перезаписывает файлы, не трогая заказы).

## Локальная разработка (Node)

```bash
npm install
npm start                 # http://localhost:3000
```

Доступы берутся из `public/.env`. Без доступов сайт работает в
**демо-режиме**: расчёт доставки и оплата заменяются заглушками.

## Подключение Т-Банк (интернет-эквайринг)

1. Подключите интернет-эквайринг к расчётному счёту ИП:
   <https://developer.tinkoff.ru/eacq/intro/connection>
2. В личном кабинете возьмите **Terminal Key** и **Password** терминала.
3. Заполните в `.env`: `TINKOFF_TERMINAL_KEY`, `TINKOFF_PASSWORD`.
4. Укажите систему налогообложения ИП в `TINKOFF_TAXATION`
   (`usn_income` и т.п.) — она попадает в чек 54-ФЗ.
5. Notification URL для статусов оплаты:
   `https://<домен>/api/payment/notify` — прописывается из `BASE_URL`.

Поток оплаты: `/api/orders` → `Init` → редирект на платёжную форму Т-Банк →
вебхук `/api/payment/notify` обновляет статус заказа.

## Подключение СДЭК (API v2)

1. Заключите договор и получите доступы к API:
   <https://www.cdek.ru/ru/integration/>
2. Заполните в `.env`: `CDEK_ACCOUNT`, `CDEK_SECURE_PASSWORD`.
3. Укажите отправителя: `CDEK_SENDER_CITY_CODE`, `CDEK_SENDER_POSTAL_CODE`
   и код склада/ПВЗ отгрузки `CDEK_SHIPMENT_POINT`.
4. Тестовый контур: `CDEK_API=https://api.edu.cdek.ru/v2`.

Возможности: подсказка городов, список ПВЗ, расчёт тарифа склад-склад (136)
и склад-дверь (137), создание заказа.

## Оплата при получении

Способ «Оплата при получении» оформляется как **наложенный платёж СДЭК**:
в заказе СДЭК позиции получают `payment.value` = стоимость товара, а
стоимость доставки — `delivery_recipient_cost`. СДЭК принимает деньги с
получателя при выдаче и переводит их продавцу по договору.
