# Skywood.club

Сайт-магазин подвесных палаток и гамаков-палаток Skywood: лендинг с видео,
оплата через **Т-Банк** и доставка **СДЭК** (включая оплату при получении).

Продавец: ИП Сурков К.А., ИНН 773135420168.

Статический HTML + PHP-бэкенд. Работает на обычном PHP-хостинге.

## Установка на хостинг

1. Залейте файлы сайта в каталог на хостинге (или обновите их через
   `pull.php` — откройте его в браузере).
2. В панели хостинга выберите для сайта **PHP 7.4 или 8.x**.
3. Откройте `install.php` в браузере — он проверит хостинг. Все пункты
   должны быть зелёными.
4. Заполните доступы в файле `.env` (см. ниже) и обновите страницу
   `install.php`.

Обновление сайта в дальнейшем — просто откройте `pull.php`: он подтянет
свежие файлы из GitHub. Заказы при этом не теряются.

## Доступы — файл `.env`

Все доступы хранятся в файле `.env` рядом с `index.html`.

### Т-Банк (интернет-эквайринг)

1. Подключите интернет-эквайринг к расчётному счёту ИП:
   <https://developer.tinkoff.ru/eacq/intro/connection>
2. В личном кабинете возьмите **Terminal Key** и **Password** терминала.
3. Впишите в `.env`: `TINKOFF_TERMINAL_KEY`, `TINKOFF_PASSWORD`.
4. `TINKOFF_TAXATION` — система налогообложения ИП (`usn_income` и т.п.).

### СДЭК (API v2)

1. Заключите договор и получите доступы к API:
   <https://www.cdek.ru/ru/integration/>
2. Впишите в `.env`: `CDEK_ACCOUNT`, `CDEK_SECURE_PASSWORD`.
3. Укажите отправителя: `CDEK_SENDER_CITY_CODE`, `CDEK_SENDER_POSTAL_CODE`,
   код склада/ПВЗ отгрузки `CDEK_SHIPMENT_POINT`.

Пока доступы не заданы, сайт работает в демо-режиме (оплата и расчёт
доставки — заглушки).
