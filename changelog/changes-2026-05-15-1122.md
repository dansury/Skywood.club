# 2026-05-15 — Full site redesign

Skywood.club rebuilt from a WordPress/WooCommerce export into a custom
Node.js selling landing with Tinkoff payments and CDEK delivery.

## Added

- `package.json`, `.env.example`, `.gitignore` — Node.js 18+/Express project.
- `src/server.js` — Express app: static frontend, API routes, payment result pages.
- `src/config.js` — env-driven config; `demoMode` flag.
- `src/catalog.js` — product catalog loader.
- `src/store.js` — JSON-file order store (`data/orders.json`).
- `src/services/tinkoff.js` — Tinkoff EACQ client: `Init`, `GetState`,
  token signing, 54-FZ receipt, notification verification.
- `src/services/cdek.js` — CDEK API v2 client: OAuth, city search, pickup
  points, tariff calculation, order creation with COD support.
- `src/routes/cdek.js`, `orders.js`, `payment.js` — REST API; demo fallbacks.
- `data/products.json` — catalog: Гамак-палатка Skywood, Подвесная палатка Jet.
- `public/index.html` — selling landing: video hero, parallax, catalog,
  advantages, comparison, delivery steps, reviews, FAQ.
- `public/order.html` — order status page (`/order/success`, `/order/fail`).
- `public/css/styles.css` — dark forest theme, parallax, reveal animations, responsive.
- `public/js/store.js` — catalog, cart (localStorage), 3-step checkout.
- `public/js/main.js` — parallax, scroll header, mobile nav, reveal observer.
- `public/assets/img/*` — 14 product photos + logos extracted from old MHT.
- `spec.md`, `spec/{frontend,backend,integrations}.md`, `README.md`.

## Changed

- Old site MHT archives moved to `1/`.

## Payment & delivery

- Tinkoff EACQ: online card payment; webhook `/api/payment/notify`.
- CDEK: ship-from-warehouse tariffs 136 (PVZ) / 137 (courier).
- Cash on delivery — CDEK наложенный платёж (`payment.value` per item +
  `delivery_recipient_cost`).
