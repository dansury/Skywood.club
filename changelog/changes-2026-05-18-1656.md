# 2026-05-18 — Fix debug-mode output corrupting JSON

Follow-up to the 2026-05-17 debug mode. On a PHP 8.5 host, `display_errors`
in debug mode printed a `curl_close()` deprecation into the response body,
breaking JSON parsing on the client.

## Changed

- `api/lib/http.php` — removed the `curl_close()` call (deprecated since PHP
  8.5, a no-op since 8.0; the handle is freed by GC).
- `api/lib/debug.php` — added `sw_debug_install_handlers()`: in debug mode PHP
  warnings/notices/deprecations and fatals are recorded into the request trace
  instead of being printed to the output stream.
- `api/index.php` — debug mode no longer enables `display_errors`; it installs
  the trace handlers, so the JSON response stays clean.
