# 2026-05-16 — Hybrid: PHP backend + static deploy

Ported the backend to PHP so the whole site runs on shared PHP hosting,
deployable as plain files. The Node backend is kept for local development.

## Added

- `public/api/index.php` — PHP API front controller (router + order/CDEK
  validation, demo fallbacks).
- `public/api/lib/{config,http,catalog,store,tinkoff,cdek}.php` — PHP modules
  mirroring `src/`: env-driven config, cURL client, catalog, JSON order store,
  Tinkoff EACQ client, CDEK API v2 client.
- `public/install.php` — installer / hosting check (PHP version, extensions,
  `data/` folder, `.env`, configured integrations).
- `public/.htaccess` — `api/*` → `api/index.php` rewrite; deny rules for
  `.env`, `pull-config.php`, logs.
- `public/data/.htaccess` — denies web access to order data and the catalog.
- `spec/deploy.md` — hosting layout, `pull.php`, `install.php`.

## Changed

- Moved `data/` → `public/data/` and `.env` → `public/.env` so the deployable
  `public/` folder is self-contained.
- Header video placed at `public/assets/video/hero.mp4`.
- Frontend asset/API references made relative (`index.html`, `order.html`,
  `js/store.js`) — the site now works from any subfolder.
- Order result is now `order.html?order=<id>&status=success|fail`;
  `order.html` reads the `status` query param.
- Node `config.js`/`catalog.js`/`store.js` updated for the moved `.env` and
  `data/` paths.
- `pull-config.php` `subdir` set to `public`.
- `spec.md`, `spec/backend.md`, `spec/integrations.md`, `README.md` updated for
  the hybrid architecture.

## Notes

- API contract is identical for PHP and Node — change both together.
- PHP routing needs Apache `mod_rewrite`; `index.php` also accepts
  `?route=<route>` as a fallback.
