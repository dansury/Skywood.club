# 2026-05-17 — Product card gallery: swipe + hover navigation

Made the catalog card photo gallery navigable beyond the dot indicators.

## Changed

- `js/store.js` — `productCard()` now routes image switching through a single
  `setImage(idx)` helper (clamped, no-op on the current index); dot clicks use
  it. Card galleries with more than one photo get `bindGalleryNav()`.
- `js/store.js` — new `bindGalleryNav(media, images, setImage, getIdx)`:
  - preloads non-first frames so switching is instant;
  - touch swipe left/right on `.product__media` (40 px threshold, ignores
    mostly-vertical gestures) → previous/next photo;
  - desktop hover: `mousemove` maps the cursor's horizontal position over the
    media to a photo index; `mouseleave` returns to the first photo.

## Notes

- The product modal gallery already had swipe and ←/→ keyboard navigation;
  left unchanged.
