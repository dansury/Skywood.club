# 2026-05-17 — Debug mode + CDEK city cache & diagnostics

Added a site-wide debug mode and tooling to find out why the CDEK city
autocomplete fails (bad key vs. broken code).

## Added

- `api/lib/debug.php` — debug-mode helpers. `?debug=1` (or `X-Sw-Debug: 1`)
  on any `/api/*` request turns it on: `sw_debug_enabled()`, `sw_debug_add()`
  request trace, `sw_debug_dump()`, `sw_debug_mask()` (hides secrets).
- `GET /api/cdek/diag` — CDEK self-check: config (account, official API URL),
  OAuth test, city-search test; `result` says whether a failure is in the key
  or in the code.
- `js/store.js` — debug panel (fixed, bottom): logs every API request/response
  plus the server trace, catches JS errors, buttons «Проверить СДЭК»,
  «Скопировать всё», «Очистить», «Свернуть». `apiPath()`/`apiFetch()` wrappers.
- `order.html` — `?debug=1` shows a panel with the order response and trace.
- `.sw-debug` styles in `css/styles.css`.

## Changed

- `api/lib/cdek.php` — `sw_cdek_token()` now throws
  `CDEK OAuth: <error_description>` instead of a generic message, so the real
  cause is visible. `sw_cdek_search_cities()` caches results per query to
  `data/.cdek-cities.json` (TTL 30 days, `SW_CDEK_CITIES_TTL`); debug mode
  ignores the cache and rewrites it fresh.
- `api/lib/http.php` — traces every cURL call into the debug log.
- `api/index.php` — loads `debug.php`; enables PHP `display_errors` when debug
  is on; `sw_json()` emits the trace via the `X-Sw-Debug` header and a `_debug`
  key on object responses; the top-level `catch` records the exception.
- `js/store.js` — all API calls routed through `apiFetch()`; CDEK errors
  (cities/points/calculate) show the real message in debug mode.
- `.gitignore` — ignore `data/.cdek-cities.json`.

## Notes

- CDEK endpoints in use are the official API v2 (`api.cdek.ru/v2`):
  `/oauth/token`, `/location/cities`, `/deliverypoints`, `/calculator/tariff`,
  `/orders`. `/api/cdek/diag` reports `officialApi: true` when configured so.
- Run `/api/cdek/diag?debug=1` on the live host to see whether OAuth fails
  (key problem) or the city request fails (code/endpoint problem).
