# 2026-05-18 — CDEK city autocomplete by partial input

## Changed

- `api/lib/cdek.php` — `sw_cdek_search_cities()` now calls the official
  `GET /location/suggest/cities` endpoint (`name`, `country_code`) instead of
  `/location/cities`. `/location/cities` matched the city name exactly, so the
  autocomplete only worked once the full name was typed; `suggest/cities` is
  built for partial input («Мос» → Москва, Мосальск …). Entries without a CDEK
  `code` are skipped; `full_name` is split into `city` / `region`. Per-query
  caching is unchanged.
