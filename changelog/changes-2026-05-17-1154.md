# 2026-05-17 — Product video as the second card gallery frame

The product `video` now appears as the second frame of the catalog card
gallery, loaded lazily after the page finishes loading.

## Changed

- `js/store.js` — `productCard()` builds a `frames` model: first photo,
  then the product video (when `product.video` is set), then the remaining
  photos. A `<video class="product__video" preload="none" data-src=...>` is
  layered over the card image; `setImage()` shows/plays it on the video
  frame and pauses it otherwise.
- `js/store.js` — `loadProductVideos()` sets each card video's real `src`
  from `data-src` after `window.load` (or immediately if the page is
  already loaded), so card videos never compete with initial page load.
  `setImage()` also assigns the `src` on demand if the video frame is
  reached first.
- `js/store.js` — `bindGalleryNav()` takes the `frames` array; preloads
  only image frames; swipe/hover index math uses `frames.length`.
- `css/styles.css` — `.product__video` (absolute, `object-fit:cover`,
  opacity fade, hover scale matching the image).
- `data/products.json` — `jet.video` corrected to `SkywoodJet.mp4` to
  match the actual file name (case-sensitive hosting would 404 otherwise).
