# Видео для шапки сайта

Положите сюда атмосферный ролик под именем **`hero.mp4`**:

```
public/assets/video/hero.mp4
```

Сайт автоматически подхватит его как фон секции Hero. Пока файла нет,
показывается постер-изображение `/assets/img/jet-1.jpg` — сайт работает без видео.

Рекомендации к ролику:

- формат **MP4 (H.264)**, разрешение 1920×1080;
- длительность 10–25 секунд, зацикленный (loop);
- вес до ~6–8 МБ — видео грузится на всех устройствах;
- без звука (воспроизводится в режиме muted);
- спокойная сцена: лес, кроны деревьев, рассвет.

Для лучшей поддержки можно дополнительно положить `hero.webm`
и добавить второй `<source>` в `index.html`.
