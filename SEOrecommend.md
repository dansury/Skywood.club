# SEO-аудит и рекомендации — skywood.club

Аудит проведён по методологии плагина [claude-seo](https://github.com/AgriciDaniel/claude-seo)
(`/seo audit`, `/seo technical`, `/seo schema`, `/seo ecommerce`, `/seo geo`).
Плагин — это набор команд для Claude Code; полноценный запуск `/seo audit`
с подключением Google Search Console / PageSpeed даст более точные метрики.
Ниже — анализ кода сайта и приоритизированные рекомендации.

> Установка плагина (на машине разработчика):
> ```
> /plugin marketplace add AgriciDaniel/claude-seo
> /plugin install claude-seo
> /seo audit https://skywood.club
> ```

## 1. Технический SEO

| Что | Статус | Рекомендация |
|---|---|---|
| HTTPS | предположительно ок | Убедиться, что весь трафик принудительно идёт на `https://` (HSTS). |
| Канонический домен | ⚠ | Выбрать один: `skywood.club` **или** `www.skywood.club`, и 301-редиректить второй на первый. Сейчас часть путей живёт в подкаталоге `/NEW/` — на проде перенести в корень домена. |
| `BASE_URL` в `.env` | ⚠ | Стоит `https://skywood.club/NEW`. На проде заменить на корень `https://skywood.club`, иначе canonical/sitemap/редиректы и URL оплаты будут расходиться. |
| Sitemap | ✅ добавлен | После запуска отправить `sitemap.xml` в Яндекс.Вебмастер и Google Search Console. |
| 404 | ⚠ | Сделать дружелюбную 404-страницу с ссылкой на каталог. |
| Скорость | ⚠ | Видео hero (`hero.mp4`) — самый тяжёлый ресурс. Сжать (H.264, ~720p, target ≤ 3–4 МБ), добавить `preload="none"` + клик-to-play на мобильных; держать `poster`. Изображения — отдавать в WebP/AVIF. |

## 2. Контент и On-page

- **Один H1 на главной** — сейчас ок (`Лучшие способы зависать`). Стоит сделать
  его более ключевым: добавить слова «подвесная палатка / гамак-палатка».
- **Title главной** хороший и насыщенный — оставить.
- **Уникальные описания товаров** уже есть в `products.json` — хорошо для
  длинных запросов.
- **Старые URL были отдельными страницами товаров.** Для максимального
  сохранения трафика в идеале сделать отдельные страницы под каждый товар
  (`/hammock`, `/jet`) с уникальными Title/Description и редиректить старые URL
  на них, а не на главную. Сейчас — редирект на главную (приемлемо для лендинга).

## 3. Структурированные данные (Schema.org)

- Добавлен `Store`. **Рекомендуется** добавить `Product` + `Offer` для каждого
  товара (цена, наличие, валюта) и `AggregateRating`/`Review` (отзывы на сайте
  уже есть — их можно разметить). Это даёт «rich snippets» в выдаче.
- Добавить `BreadcrumbList` и `Organization` с логотипом.
- Цены и наличие можно отдавать в JSON-LD динамически из `/api/products`
  (поля `price`, `oldPrice`, `available`, `preorder`).

## 4. E-commerce

- **Наличие/предзаказ** теперь отражается на витрине — для Schema используйте
  `availability`: `InStock` / `PreOrder` / `OutOfStock`.
- Микроразметка цены со скидкой (`priceValidUntil` = срок действия скидки из
  админки) усилит сниппет распродажи.

## 5. AI-поиск / GEO (генеративные движки)

- Добавить блок FAQ в разметку `FAQPage` JSON-LD (на сайте уже есть секция FAQ —
  разметить её). Это хорошо индексируется и ИИ-поиском, и Google.
- Чёткие фактические ответы (вес, нагрузка, размеры) — уже есть в `specs`, их
  стоит вынести в `Product` schema как `additionalProperty`.

## 6. Локальный SEO

- Создать/заполнить карточки в Яндекс.Бизнес и 2ГИС (если есть пункт
  самовывоза/шоурум), единый NAP (Name-Address-Phone) на сайте и в карточках.
- Телефон в разметке уже есть.

## 7. Аналитика

- Яндекс.Метрика (ID `89161768`) подключена — настроить **цели**: «оформлен
  заказ», «предзаказ», переход к оплате. Передавать e-commerce dataLayer
  (товар, цена) при добавлении в корзину и покупке.
- Подключить Google Search Console и Яндекс.Вебмастер, отправить sitemap,
  отслеживать, что 301-редиректы со старых URL индексируются корректно.

## Приоритеты

1. **Высокий:** выставить прод-домен в корне (`BASE_URL`, canonical), отправить
   sitemap в вебмастеры, проверить работу 301-редиректов на живом хостинге.
2. **Высокий:** сжать hero-видео и изображения (скорость = ранжирование + UX).
3. **Средний:** `Product`/`Offer`/`FAQPage` JSON-LD.
4. **Средний:** отдельные страницы товаров под старые URL.
5. **Низкий:** локальные карточки, расширенная разметка отзывов.
